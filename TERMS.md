## Program description

Pager is a test program run by Albert Wong. If you have agreed to participate, you will receive two-way conversational text messages relayed from a Pager device, such as messages coordinating where and when to meet, and your replies will be relayed back to that device. Messages are written by people, not generated automatically.

## Message frequency

Message frequency varies. Messages typically arrive in bursts on days when you are coordinating with the Pager user.

Message and data rates may apply.

## Help and opt-out

**Reply HELP to any message for help, or email awong.dev@gmail.com.**

**Reply STOP to any message to opt out. You will receive one final confirmation message and no further messages.**
